# Font Reader Chrome Extension

## Setup

1. Open Chrome and go to `chrome://extensions/`
2. Enable **Developer mode** in the top right
3. Click **Load unpacked**
4. Select the folder: `/home/mossaddak/extensions/fontreader`

## Usage

1. Open a normal website page (not `chrome://` or local `file://` unless file access is enabled)
2. Click on the text or element you want to inspect
3. Click the extension icon in the Chrome toolbar
4. Click **Read Font Info**

## What it reads

- font family
- font size
- color
- font weight
- font style
- text decoration
- text transform
- line height
- letter spacing
- element selector

## Notes

- The extension must be loaded as an unpacked extension in Chrome.
- If the toolbar icon is hidden, click the puzzle-piece icon and pin "Font Reader".
